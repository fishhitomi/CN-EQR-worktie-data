# WORKTIE 变量构造说明

对应论文：Qi, Seidel, Zhang & Zhang (2026, JAR) —— EQR 与项目合伙人的既往共事经历（WORKTIE）。

## 1. 变量口径（与论文一致）

`WORKTIE`：公司-年层面 0/1 变量，等于 1 表示该年度审计项目的质量控制复核人（EQR）**此前**曾与两位签字项目合伙人中的至少一位，在**同一上市公司审计/资本市场项目**上共同作为签字审计师执业（不含当前客户、不含 EQR-合伙人这种监督关系）。

共事来源包括 CSMAR 审计意见表中的**年度审计签字记录**，以及 CSMAR **资本市场项目签字记录**（IPO 申报企业、增发、配股三张表）。项目年份需严格早于当前审计年度（`项目年份 < 审计年度`）才计为“此前共事”。

## 2. 数据来源

| 数据 | 用途 |
| --- | --- |
| 巨潮资讯网公告（63,209 份 PDF） | 提取 EQR 姓名（拟聘任/拟续聘/续聘/变更/质量控制复核人等公告） |
| `FIN_Audit.dta`（审计意见表，1998–2023） | 各公司-年度签字合伙人、审计意见、事务所 |
| `AR_LISTCOMPAUDIT.dta`（审计机构列表） | 姓名 → PersonID 映射（精确到人） |
| `AR_CPAINFO.dta`（CPA 个人情况表） | 姓名 → PersonID 补充映射 |
| `CPA_MARK.dta`（外部CPA数据，含出生日期） | EQR 姓名库校验 |
| `IPO_NEWSHARECO.xlsx`（IPO 新股发行申报企业情况表） | IPO 项目签字会计师（`SignAccountant`），披露日期 |
| `RS_Aibasic.xlsx`（上市公司增发发行基本情况） | 增发项目会计师经办人（`Aicpa`），意向书签署/发表日等 |
| `RS_Robasic.xlsx`（上市公司配股基本情况） | 配股项目会计师经办人（`Aicpa`），说明书发表/签署日等 |

资本市场项目表已解压至 `00_原始数据/CSMAR/资本市场项目/`，构建脚本自动读取；原 zip 保留存档。

## 3. 处理流程

1. **公告搜索**（`02_代码/02_EQR提取/01_搜索公告清单.py`）：标题检索“聘任/续聘/聘请/变更/会计师事务所/审计机构/质量控制复核人”等 32 个关键词，2019-10-01 至 2024-07-01，去重后 **63,210 条**相关公告。
2. **PDF 下载**（`02_下载公告PDF.py`）：全部下载至 `00_原始数据/巨潮公告/公告PDF_全量/`，断点续传，0 失败。
3. **EQR 提取**（`03_提取EQR姓名.py`）：pdftotext 提取文本，规则解析“项目质量控制复核人/质量控制复核人/质量控制负责人/独立复核合伙人/质量复核人员/复核合伙人”等 13 种表述；支持“：姓名”“为XX先生”“XX担任质量复核人员”“表格排版（名字紧接标签）”等格式；用 8.3 万 CPA 姓名库校验并过滤碎片。
4. **审计年度校正**（`02_代码/03_变量构建/01_构建WORKTIE.py`）：标题含“20XX年度”优先；无标题年度时优先采用提取层年度（公告标题/正文模式与年份频率，须经 FIN_Audit 校验），再以公告月份推断（10 月及以后视为次年审计）兜底。
5. **共事网络构建**：从 FIN_Audit 1998–2023 全部签字记录构建“签字人-签字人”共事边（PersonID 优先、姓名兜底），边记录项目（公司、年度、类型 AUD）。
6. **资本市场项目共事边**：读取 IPO/增发/配股三张表，清理说明行与“没有单位”等占位值，姓名去掉“（已离职）”等备注；同一项目按“类型+公司+年度+签字人集合”去重后，同样构建“签字人-签字人”共事边（类型 IPO/SEO/RIO）。项目年度规则：
   - IPO：披露日期所在年度；
   - 增发：取意向书签署日、意向书发表日、发行开始日、上市公告发表日、上市流通日中的最早年份；
   - 配股：取说明书发表日、说明书签署日、上市流通日中的最早年份。
7. **WORKTIE 计算**：对 2020–2023 每个公司-年，若 EQR 与任一签字合伙人在 t 年之前存在共事边，则 WORKTIE=1。同时输出 `WORKTIE_ENG1_ENG2`（两位合伙人之间的既往共事）。

## 4. 输出文件

`WORKTIE_2020-2025.csv` 字段：

| 字段 | 说明 |
| --- | --- |
| `stkcd` / `year` | 公司代码（6 位）/ 审计年度 |
| `eng1_name` / `eng2_name` | 第一、第二签字项目合伙人 |
| `eng1_pid` / `eng2_pid` | 对应 PersonID（可多个） |
| `eqr_name` / `eqr_pid` | 质量控制复核人姓名及 PersonID |
| `eqr_ann_date` | EQR 信息来源公告日期（取该年度最新公告） |
| `worktie` | 核心解释变量 0/1 |
| `worktie_eng1` / `worktie_eng2` | EQR 与第一/第二签字合伙人分别是否有既往共事 |
| `worktie_eng1_eng2` | 两位项目合伙人既往共事 0/1 |
| `tie_count` | 既往合作项目数（去重后，年报+资本市场项目） |
| `tie_count_eng1` / `tie_count_eng2` | EQR 与第一/第二合伙人各自的合作项目数 |
| `tie_first_year` / `tie_last_year` | 首次 / 最近一次合作年份 |
| `tie_recency` | 距最近一次合作的时间间隔（审计年度 − 最近合作年份） |
| `tie_has_aud` / `tie_has_ipo` / `tie_has_seo` / `tie_has_rio` | 是否含年报 / IPO / 增发 / 配股类共事项目 |
| `tie_has_capital` / `tie_high_complexity` | 是否含资本市场项目（IPO/增发/配股，视为高复杂度） |
| `tie_similar_industry` | 既往共事项目中是否有与当前客户同行业（证监会行业代码）的项目 |
| `tie_same_province` / `tie_same_city` | 既往共事项目中是否有与当前客户同省 / 同城市的项目 |
| `tie_similar_client` | 相似客户综合指标：同行业或同城市 |
| `tie_projects` | WORKTIE=1 时的共事项目明细（公司-年度），含类型前缀：AUD（年报）、IPO、SEO（增发）、RIO（配股） |

相似客户所用的行业/地区映射来自 外部数据 年度行业代码表（2001–2024）与公司文件；早年或缺失年份用公司文件静态行业/地区兜底。高复杂度目前以“是否为资本市场项目”作为代理，后续可再并入客户规模、审计费用、关键审计事项数等更细口径。

另输出 `共事边_资本市场项目.csv`：全部已清理并去重的资本市场项目记录（类型、公司/代码、年度、日期、签字人）。

`--no-capital` 参数可复现旧口径（仅年报签字），输出到 `WORKTIE_2020-2023_仅年报.csv`，不覆盖主交付文件。

最终交付数据集为 `03_输出/WORKTIE_2020-2024.dta`：样本区间 2020–2024，剔除金融业、年末 ST/PT、无 EQR 披露的公司-年，不因缺控制变量删样本；含 30 个变量（WORKTIE 系列、共事项目明细、签字审计师姓名与 PersonID 标识），每个变量均带中文标签，0/1 变量带「否/是」值标签。复现脚本：`02_代码/03_变量构建/03_核心变量dta.py`。

> 注：交付版 dta 中，个别 PersonID 长串（多个 ID 拼接）因生成时字符串宽度限制被截断（约 53 个公司-年，仅影响标识字段，不影响 WORKTIE 变量）；重跑上述脚本可得完整未截断的 PersonID。

## 6. 已知局限

1. **EQR 覆盖 69.1%**（2026-08-06 三步补全后）：已提取 18,343/63,210 条公告，覆盖 13,114 个公司-年。剩余 5,858 个缺口主要为：公告正文只作独立性声明而未披露 EQR 姓名或格式特殊未提取（约 3,588）、窗口内有提取但未映射到当年（2,136）、完全无命中公告（134）。论文仅有 857 个缺失，差异主要来自部分公告确实未披露 EQR 与少数标题未命中。
2. **2025 受 CSMAR 数据限制**：已下载并提取 2024-07 至 2026-08 新增公告（37,200 条，其中 13,337 条提取到 EQR），2024 覆盖升至 86.4%；但 CSMAR FIN_Audit 2025 年仅 56 条，故 2025 只能构建 47 个公司-年，需 CSMAR 更新后才能完整。
3. **PDF 已精简**：两轮共删除 70,306 份未命中 EQR 的 PDF（约 114.6 GB）；正式目录仅保留 31,680 份命中 PDF（6.7 GB）。如需恢复或重新下载，公告清单与 URL 仍保存在 `02_中间数据/巨潮公告清单/`。
4. **资本市场项目类型不全**：已并入 IPO、增发、配股三类；论文口径还包括可转债/公司债、重大资产重组等，此类项目若后续提供可直接并入共事网络重算。
5. **IPO 表以披露记录为单位**：同一公司同一 IPO 在不同披露阶段（预披露、问询回复、注册生效等）可能多次出现，本项目按“公司+年度+签字人集合”合并；不同年度仍保留为多个项目记录。
6. **姓名重名**：部分重名通过 PersonID 消歧；个别历史记录缺失 PersonID 时退化为姓名匹配，可能高估极少数联结。
7. **EQR 变更**：同一年度多条公告时取最新公告的 EQR（与论文“用最新公告”一致）；变更公告同时列出新旧 EQR 时取新任复核人；“暂未确定”“翁祖桂无”等碎片已在构建时过滤。
8. **相似客户/高复杂度为简化代理**：同行业按证监会行业代码（细分代码）比较，早年用静态行业兜底；高复杂度以资本市场项目作为代理，未含客户规模/审计费用等口径。
