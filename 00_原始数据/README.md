# 原始数据说明

> **重要提示**：本文件夹中的 CSMAR/CNRDS 数据受版权许可限制（原文件名含机构授权标识），未上传至 GitHub 仓库。以下为数据来源说明，请通过正规渠道获取。

## 数据来源

本项目使用以下原始数据：

| 数据 | 来源 | 内容 | 用途 |
|---|---|---|---|
| 审计意见表 | CSMAR | 1998–2025 年报签字合伙人、审计意见、事务所 | 共事网络构建（年报签字） |
| 上市公司审计机构列表 | CSMAR | code-year → 事务所、签字审计师姓名与 PersonID | 姓名→PersonID 映射 |
| 中国注册会计师个人情况表 | CSMAR | CPA 快照（2017–2025），所在事务所 | 姓名→PersonID 补充映射 |
| IPO 新股发行申报企业情况表 | CSMAR 资本市场项目 | IPO 项目签字会计师（SignAccountant） | 资本市场项目共事边 |
| 上市公司增发发行基本情况 | CSMAR 资本市场项目 | 增发项目会计师经办人（Aicpa） | 资本市场项目共事边 |
| 上市公司配股基本情况 | CSMAR 资本市场项目 | 配股项目会计师经办人（Aicpa） | 资本市场项目共事边 |
| 注册会计师信息 | CNRDS | CPA 基本信息 | 辅助校验 |
| 巨潮公告 PDF | 巨潮资讯网（公开） | 63,209 份聘任/变更/质控复核公告 | EQR 姓名（自行抓取，未上传） |

## 获取方式

### CSMAR 数据

1. 访问 [CSMAR 官网](https://www.gtarsc.com/)
2. 通过所在机构（高校/研究院）的 CSMAR 数据库订阅权限下载
3. 下载后将 zip 文件放置于本文件夹的 `CSMAR/` 子目录中
4. 脚本通过通配符匹配自动查找文件（无需关心文件名中的机构标识）

### CNRDS 数据

1. 访问 [CNRDS 官网](https://www.cnrds.com/)
2. 通过所在机构订阅权限下载

### 巨潮公告

1. 公告通过巨潮资讯网公开 API 抓取（脚本：`02_代码/02_EQR提取/`）
2. PDF 文件因体积过大（6.7GB）未上传，可通过公告清单中的 URL 重新下载

## 外部数据依赖（可选）

部分脚本依赖项目外部的数据集，需通过环境变量配置：

| 环境变量 | 说明 | 用于脚本 |
|---|---|---|
| `EARNINGS_MGMT_DIR` | 应计盈余管理数据目录（公司文件.dta、是否ST或PT.dta、基础数据.dta、计算结果.dta） | `03_核心变量dta.py`、`02_对照论文_样本与描述统计.py` |
| `DATAWEB_AUDIT` | 审计质量/审计激进度数据目录（公司文件.dta） | `01_构建WORKTIE.py` |
| `DATAWEB_FORECAST` | 分析师预测数据目录（行业代码.dta、总股数.dta） | `01_构建WORKTIE.py`、`02_对照论文.py` |
| `CPA_MARK_DTA` | CPA 标记数据路径（CPA_MARK.dta，含出生日期） | `03_提取EQR姓名.py`、`02_对照论文.py` |
| `GEO_DISTANCE_DTA` | 审计地理距离数据路径（异地审计_地理距离_2000-2024.dta） | `02_对照论文.py` |
| `CSMAR_BALANCE_ZIP` | CSMAR 资产负债表 zip 路径 | `02_对照论文.py` |
| `PRICE_DATA_DIR` | 股价数据目录（股价.xlsx） | `02_对照论文.py` |

注意：核心 WORKTIE 变量构建（`01_构建WORKTIE.py`）的外部依赖为可选（已有存在性检查保护），`03_核心变量dta.py` 的外部依赖为必需（用于行业/ST 筛选）。
