## 项目概览

本仓库目前包含以下数据集：

### 质量控制复核人（EQR）与签字审计师工作联结（WORKTIE，2020–2024）

参考文献：Qi, Seidel, Zhang & Zhang (2026), *Do Engagement Quality Reviewers' Workplace Ties with Engagement Partners Influence Audit Quality?*, Journal of Accounting Research.

以**公司-年度** 为观测单位，构建质量控制复核人（EQR）与签字项目合伙人的**既往共事经历（WORKTIE）** 变量：

- **WORKTIE**（核心 0/1）：EQR 此前曾与两位签字合伙人中的至少一位在同一上市公司审计或资本市场项目上共同签字执业（不含当前客户）
- **WORKTIE_ENG1_ENG2**：两位合伙人之间的既往共事 0/1
- **扩展变量**：合作次数、最近合作时间、项目类型（年报/IPO/增发/配股）、相似客户（同行业/同城市）、高复杂度项目

共事来源包括 CSMAR 审计意见表（年报签字）和 CSMAR 资本市场项目签字记录（IPO/增发/配股）。EQR 姓名通过巨潮公告自行抓取提取。

**数据规模**：16,497 个公司-年观测 × 30 个变量（2020–2024，已剔除金融业/ST/无 EQR），WORKTIE 均值 8.7%（1,433 个共事观测），与论文 9.2% 接近。除 WORKTIE 变量外，还配套提供签字审计师姓名（`eng1_name`/`eng2_name`/`eqr_name`）与 PersonID 等标识变量，全部带中文标签。

## 快速开始

### 环境要求

- Python 3.8+
- pandas、openpyxl（读取 xlsx）
- pdftotext（TeX Live，用于 PDF 文本提取）
- Stata（仅查看 .dta 文件需要）

### 复现步骤

1. **获取原始数据**：通过所在机构的 CSMAR/CNRDS 订阅权限下载数据压缩包，放入 `00_原始数据/`（详见该文件夹内 README）

2. **配置外部数据**（可选，用于扩展变量）：设置环境变量，见 `00_原始数据/README.md` 中"外部数据依赖"

3. **按序执行脚本**：

```bash
# 1) 搜索公告清单（需联网）
python 02_代码/02_EQR提取/01_搜索公告清单.py

# 2) 下载 PDF（需联网）
python 02_代码/02_EQR提取/02_下载公告PDF.py --list 01_中间数据/巨潮公告清单/公告清单_下载.csv

# 3) 提取 EQR 姓名
python 02_代码/02_EQR提取/03_提取EQR姓名.py --list 01_中间数据/巨潮公告清单/公告清单_下载.csv

# 4) 构建 WORKTIE
python 02_代码/03_变量构建/01_构建WORKTIE.py

# 5) 生成最终交付 dta（需外部数据：行业/ST 筛选）
python 02_代码/03_变量构建/03_核心变量dta.py
```

4. **使用数据**：

```stata
use "03_输出/WORKTIE_2020-2024.dta", clear
sum worktie worktie_eng1_eng2
tab year worktie
```

## 使用建议

1. EQR 覆盖率为 69.1%（论文约 96%），主要缺口为部分公告未披露 EQR 姓名；2024 年覆盖率约 86.4%
2. 2025 年数据受 CSMAR 审计意见表更新限制，仅构建 47 个公司-年
3. WORKTIE 8.7% 与论文 9.2% 的差异主要来自样本口径，非匹配逻辑问题
4. 资本市场项目共事仅含 IPO/增发/配股，可转债/重组等尚未并入
5. 交付版 dta 中个别 PersonID 长串（多 ID 拼接）因生成时字符串宽度限制被截断，仅影响标识字段、不影响 WORKTIE 变量；重跑 `03_核心变量dta.py` 可得完整未截断版本
